# Radio Tec · https://radio-tec.github.io

Link fijo de **Radio Tec, la voz del Instituto Tecnológico Superior de Coalcomán**.

La radio corre en la computadora de la estación y sale a internet por un túnel de Cloudflare.
`en-linea.json` guarda la dirección vigente del túnel: lo actualiza solo `en-linea.ps1`
(del proyecto de la radio) cada vez que la radio se enciende. No lo edites a mano.
